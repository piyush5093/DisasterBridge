2. Project Statement and Outcomes: 
During disaster events, resource allocation decisions for 
food, water, medical supplies, search and rescue teams, 
and shelter are often made with incomplete information, 
resulting in critical shortages in some areas while 
resources sit idle elsewhere. This project builds a full-
stack AI-powered disaster resource management web 
platform that integrates real-time disaster event feeds, 
geospatial damage assessment data, population density 
maps, and field resource inventory to model disaster 
impact zones, predict resource demand by location, and 
generate optimized allocation and logistics plans for relief 
agencies. 
The deliverable is a disaster operations command 
platform where relief coordinators manage their resource 
inventory, view real-time disaster impact maps, and 
receive 
AI-generated 
resource 
allocation 
recommendations with deployment routes. Field teams 
access mobile-friendly mission assignments with supply 
manifests and navigation support. Post-event analytics 
modules generate comprehensive situation reports

Weeks 3ΓÇô4: Resource Demand Prediction Engine 
ΓÇó Train a regression model predicting resource

ΓÇó Build a vulnerability weighting module adjusting

ΓÇó Implement a dynamic demand update engine

ΓÇó Build scenario simulation functionality allowing

ΓÇó Expose the demand prediction service via a 
FastAPI endpoint returning zone-level resource 
demand estimates with confidence intervals.
